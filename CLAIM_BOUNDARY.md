# Runtime Claim Boundary

CDFD Runtime is software for executing explicitly declared toy models and
recording their structured, finite, reproducible outputs. It establishes only
software facts that are directly checked: parsing/execution under recorded
inputs, JSON-visible finite-output audits, result-envelope provenance, and
stored run bundles.

It does not establish that CDFL variables map to real measurements, that a
threshold is calibrated, that a numerical result converged, or that CDFD/AFL
describes a physical, biological, medical, engineering, social, or historical
system. A finite output is not empirical validation.

Any domain claim requires predeclared observable proxies, a field-native
baseline, held-out evaluation, uncertainty analysis, and a negative-result
rule. The runtime must not be described as a source of universal laws,
discoveries, clinical forecasts, particle predictions, causal proof, or a
decision system.
