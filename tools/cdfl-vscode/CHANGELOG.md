# Changelog

## 0.1.0

- Added `.cdfl` file association for the `CDFL` language mode.
- Added TextMate syntax highlighting for the current CDFD Runtime CDFL lexer keyword and token surface.
- Added bracket, indentation, folding, and line-comment editor configuration.
- Added snippets for the supported v0.1 CDFL statement forms.
- Added a marketplace icon and sharper highlighting for block names and key names.
- Added local diagnostics, completions, hovers, document symbols, and formatting.
- Added command palette actions for runtime validation, runtime linting, runtime execution, AST inspection, runtime formatting, runtime doctor, the language reference, and heat-flow sample creation.
- Added runtime configuration settings for command auto-detection, runtime working directory, and run grid size.
- Added marketplace-ready package metadata for Vura Labs publishing.
