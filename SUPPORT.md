# Support

CDFD Runtime support is scoped to the slim public research-software release:

- CLI installation and command execution
- CDFL parsing, validation, linting, formatting, and deterministic local runs
- Reproducibility artifacts, metadata, release bundles, and the public smoke experiment
- VS Code CDFL extension source under `tools/cdfl-vscode/`

Legacy domain adapters, multi-paper runtime manuscripts, Streamlit Studio, and
the old experiment corpus are archived outside the repository. See
`ARCHIVE_NOTICE_2026-08-25.md`.

The project does not provide medical, engineering, financial, legal, safety, or
deployment decisions. Runtime outputs are software diagnostics with an explicit
claim boundary, not empirical validation.
