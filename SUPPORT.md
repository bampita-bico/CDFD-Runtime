# Support

CDFD Runtime support is scoped to the public research runtime:

- CLI installation and command execution.
- CDFL parsing and deterministic local runs.
- Domain adapter smoke behavior.
- Reproducibility artifacts, metadata, and release bundles.
- Streamlit Studio as an optional visualization layer.

The project does not provide medical, engineering, financial, legal, safety, or
deployment decisions. Runtime outputs are modeling diagnostics and
falsification targets.

For questions or commercial licensing, contact `msbico@gmail.com`.
