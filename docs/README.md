# CDFD Runtime Docs

This folder holds product-facing documentation for the public runtime:

- `API.md`: CLI and Python API surfaces.
- `DOMAIN_MATURITY.md`: generated summary of registered adapter maturity.
- `domain_maturity_matrix.json`: machine-readable 196-domain matrix.
- `RELEASE_PROCESS.md`: release gates and artifact bundle flow.

The root README remains the first path for installation and five-minute use.
